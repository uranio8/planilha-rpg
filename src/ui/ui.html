Sincronização em Nuvem (Google Firebase)
Banco de Dados Firestore em Tempo Real para Celulares e Computadores
Aparelhos com o mesmo Código de Sala compartilham as mesmas fichas e combate.
100% Gratuito
📖 Como obter sua chave gratuita do Firebase (em 2 minutos)
  1. Acesse console.firebase.google.com e faça login com sua conta Google.
  2. Clique em Adicionar Projeto e dê um nome (ex: rpg-turma).
  3. No menu lateral esquerdo, clique em Criação ➔ Firestore Database e clique em Criar Banco de Dados (escolha Modo de Teste).
  4. Vá em Configurações do Projeto ⚙️ (no topo esquerdo), role até "Seus Aplicativos", clique no ícone Web </> e copie o bloco firebaseConfig.
  5. Cole o bloco no campo acima e clique em Salvar & Conectar!
