## 📌 Como Registrar Novas Issues

Ao documentar novas tarefas ou bugs:
1. Adicione a entrada na tabela acima com descrição concisa.
2. Identifique os arquivos e módulos afetados em `src_*`.
3. Valide a solução e execute `node builder.js`.
